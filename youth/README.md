# YOUTH｜青春，是一种心境

GitHub Pages 静态网页电子书部署包，包含两组漫画、共16页。

- 第一组：青春列车 · 原文共读七集（EP00–EP07）
- 第二组：失落王国 · 七词异世界冒险（EP01–EP08）
- 网站入口：index.html
- 漫画资源：images/（WebP格式，保持原始比例）

## GitHub Pages 部署

1. 将 index.html、images 文件夹和 .nojekyll 上传到仓库根目录。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch。
3. 选择 main 分支和 /(root)，保存后等待 Pages 发布。

阅读器支持章节目录、点击全屏、键盘左右键、Esc退出、手机滑动翻页和阅读进度记忆。
