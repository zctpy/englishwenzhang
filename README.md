# englishwenzhang
# 英语美文漫画共读

以 AI 伴侣剧情漫画共读经典英语文章，将原文阅读、词汇学习、情境演绎与复述练习串联起来。让经典文章变成一段看得见、记得住、可以反复阅读的旅程。

## 作品目录

### 1. What I Have Lived For｜我为何而生

英国哲学家伯特兰·罗素的经典文章。通过三组剧情漫画，陪伴读者走进爱、求知与对人类苦难的悲悯，体会一生的热情与选择。

**在线阅读：**  
https://zctpy.github.io/englishwenzhang/

### 2. Youth｜青春

萨缪尔·厄尔曼的经典散文。两组漫画沿着列车、车站、心灵电台与向上的天线展开，探讨青春、理想、勇气、热情与希望。

**在线阅读：**  
https://zctpy.github.io/englishwenzhang/youth/
